04 · the math, from my Monte Carlo course

Importance sampling, <in plain words>

the problem

Rare tails hide from darts

The false-alert rate is P(normal spend > T). At a sensible T that's around 1 in 1,500 sessions. With 8,000 plain draws you see maybe five hits, so the estimate jumps around by ±90% and you can't set a default on it.

the trick

Throw where it matters, then reweight

Draw log-spend from a proposal g that puts half its darts near the threshold and half on the real distribution (a "defensive" mixture: flip a coin, then sample that component). Each draw gets weight w = f(x)/g(x), the true density over the proposal density. Averaging w·1{x > T} is still unbiased for the tail probability, and the half-on-f part keeps every weight below 2.

g = ½·f + ½·N(ln T, σ²)
p̂ = (1/n) Σ w(xᵢ)·1{xᵢ > ln T}, w = f/g
trust check

Weights should average ≈ 1

Mean weight near 1 says the proposal covers the target. Effective sample size (Σw)²/Σw² and a running estimate with a ±1.96·SE band (CLT) tell you when to stop drawing. Efficiency ∝ 1/Var(w·1{tail}).

product example

Same move, other places

Any "how often does the bad thing happen" question with a tiny base rate fits: SLA breaches, a guardrail metric moving in an experiment, or evaluating a new ranking policy on logs collected under the old one.

On real data <sql + python>

-- 1. per-session spend for coding agents (illustrative tables)
CREATE OR REPLACE TABLE lab.finops.agent_session_spend AS
SELECT session_id, user_id, harness,
       SUM(est_cost_usd)            AS spend_usd,
       COUNT(*)                     AS turns,
       MAX(retry_streak)            AS max_retry_streak
FROM   lab.finops.gateway_requests
WHERE  request_tags['client'] = 'coding_agent'
  AND  event_date >= current_date() - INTERVAL 60 DAYS
GROUP BY ALL;

-- 2. label loops: long retry streaks = runaway
SELECT (max_retry_streak >= 25) AS runaway,
       COUNT(*) n,
       AVG(ln(spend_usd))    mu_log,
       STDDEV(ln(spend_usd)) sigma_log
FROM lab.finops.agent_session_spend
GROUP BY 1;
# 3. tail rate at candidate thresholds via importance sampling
import numpy as np
from scipy.stats import norm

rng = np.random.default_rng(102)
mu, sd = fit["mu_log"], fit["sigma_log"]

def tail_is(T, n=20_000):
    pick = rng.random(n) < 0.5                # defensive mixture g
    x = rng.normal(np.where(pick, mu, np.log(T)), sd)
    f = norm.pdf(x, mu, sd)
    w = f / (0.5*f + 0.5*norm.pdf(x, np.log(T), sd))
    h = w * (x > np.log(T))
    return h.mean(), h.std(ddof=1)/np.sqrt(n), w.mean()

for T in [30, 45, 60, 90]:
    p, se, wbar = tail_is(T)
    alerts = p * 140 * 1000          # per 1k dev-months
    print(T, round(alerts), f"rel.err={se/p:.1%}", round(wbar, 2))
